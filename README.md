# OAiP-Laba4

Лабораторная работа №4 по **Основам алгоритмизации и программирования**
(БГУИР), тема «Многомерные массивы», **вариант 5**. Три задачи на Си
и оформленный отчёт: титульный лист, условия, ход решения, блок-схемы,
листинги и окна терминала с реальным выводом.

## Задачи

| № | Условие (вариант 5) | Файл |
|----|---------------------|------|
| 1 | Количество столбцов матрицы, не содержащих ни одного нуля | `home/1/main.c` |
| 2 | Номер первой строки с положительным элементом; знаки предыдущей строки — на противоположные | `home/2/main.c` |
| 3 | Максимальный элемент в 1-й области квадратной матрицы | `home/3/main.c` |

## Структура

```
home/1/main.c … 3/main.c   задачи
home/report/               отчёт: main.typ, main.pdf, assets/, schemes/
home/Makefile              сборка программ, схем, окон терминала и PDF
template/oaip.typ          шаблон отчёта
```

## Сборка

```bash
cd home
make report     # программы -> gostpadi -> term.json -> report/main.pdf
./1/main        # запуск задачи 1
make clean
```

Нужны `gcc`, `typst`, `python3` и свежий
[gostpadi](https://github.com/sehaxe/gostpadi) (`make GOSTPADI=...`).
Листинги в PDF читаются из тех же `main.c`, которые компилируются;
схемы рисуются из `report/schemes/*.c` (упрощённые копии без проверки
ввода); `report/make_screens.py` прогоняет настоящие бинарники и падает,
если вывод не совпал с ожидаемыми приглашениями.

## Общие требования лабораторной

- задачи оформлены функциями, глобальных массивов нет;
- матрица статическая, место выделено под 100×100 элементов,
  фактические размеры вводит пользователь;
- заполнение — ручное или случайными числами по выбору пользователя;
- введённая матрица выводится отдельной функцией;
- неверный ввод отвергается с повторным запросом.
