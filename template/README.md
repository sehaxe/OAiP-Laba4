# oaip.typ — шаблон отчёта по ОАиП (БГУИР)

Титульный лист по образцу кафедры, тело — в стиле препринта arXiv
(Computer Modern, шапка «линия — заголовок — линия», цель работы как
аннотация). Подключается из `home/report/main.typ`:

```typst
#import "../../template/oaip.typ": *

#show: oaip.with(
  lab: 4,
  title: "Многомерные массивы",
  group: "658304",
  variant: 5,
  student: "Дерновский А. П.",
  teacher: "Селезнев А. И.",
  city: "Минск",
  year: 2026,
  goal: [...],
)
```

Помощники:

- `listing(read("../1/main.c"), caption: [...])` — листинг с номерами строк
  (в этом отчёте переопределён на разрываемый блок, чтобы длинный код
  переносился между страницами);
- `flow("/home/report/assets/1-main.svg", caption: [...])` — блок-схема
  gostpadi, вписанная в полосу набора;
- `terminal("/home/report/assets/term.json", n: 1, caption: [...])` —
  векторное окно терминала из реального вывода `report/make_screens.py`.

Терминальные строки рисуются через `raw`, иначе Typst схлопывает пробелы
и колонки матрицы разъезжаются.
